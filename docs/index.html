FEATURES

小工具，大纵深

不是只报一个 PID 就完事——从定位、取证到处置，一条龙闭环。

双引擎合并定位

RestartManager 官方通道秒级响应；句柄表快照（NtQuerySystemInformation + DuplicateHandle）补盲，结果合并去重、互为印证。

深扫补盲

RM 看不见的只读共享占用，交给子进程隔离的全表句柄枚举：超时自动截断、部分结果回收，挂死永远不会传染父进程。

目录与多目标

多行路径、整窗拖放、目录递归展开（深度 8 / 上限 2000）。「占用文件」列把锁精确归属到目录里那一个具体文件。

句柄级明细

点选进程即拉取句柄清单：句柄值、访问权限、类型（磁盘/管道/其他）与完整路径，占用取证细到每一个句柄。

安全护栏三层

系统进程名单拦死（csrss/lsass/svchost/explorer…），危险模式默认关闭，结束与释放均有二次确认——三层防线缺一不可。

CLI / 右键集成

同体 exe --cli --json 供脚本调用；Explorer 右键「查找占用」一键直达，软件内开关完全可逆。

QUICK START

三步，终结“删不掉”

不需要安装、不需要管理员权限（普通权限即可定位）、不需要说明书。

拖进来

把删不掉的文件直接拖进窗口，或点「浏览…」选定即扫；目录、多文件一次全收。

看谁占的

列表给出每个占用进程的 PID、名称、完整路径、占用方式与来源引擎；点选行还有句柄级明细。

安全处置

勾选危险模式后结束进程，或只关掉那一个句柄；成功后还可一键删除文件并自动验证消失。

HOW IT WORKS

三条通道，互为印证

Windows 从不直接告诉你“谁占了这个文件”——WhoLock 用三种官方/半官方机制把答案拼出来。

RMRestartManager

速度 ★★★★★ ｜ 官方 API

RmStartSession / RmRegisterResources / RmGetList——微软为“安装器查询重启对象”设计的官方通道，写锁与模块占用秒级命中。

盲区：只读共享句柄不在它的模型里（实测），所以需要第二条通道补盲。

HT句柄表扫描

速度 ★★★☆☆ ｜ NtQuerySystemInformation

对系统句柄表做快照，逐条 DuplicateHandle 后反查文件路径。Anything Anywhere——只要进程开着这个文件，就逃不掉。

工程化：死句柄挂死隔离、名称解析候选门模式、64/32 位结构位移校验。

DEEP子进程隔离深扫

速度 ★★☆☆☆ ｜ 全表穷举

由子进程执行全表枚举与名称解析：预算 25 秒超时截断、部分结果回收、fork 炸弹熔断——慢而全，且永远不挂死主程序。

闭环：配合远端句柄释放（F8），只关那一个句柄、不杀整个进程。

CLI

命令行同样能打

GUI 与 CLI 同体 exe：--cli 切控制台，--json 供脚本与流水线消费。

Windows PowerShell
# 人读列表（双引擎）
wholock --cli "D:\share\报告终版.docx"

# JSON 输出 + 仅 RestartManager 引擎
wholock --cli --json --engine=rm "D:\share\报告终版.docx"

# 多目标 + 目录自动展开
wholock --cli "D:\a.txt" "D:\dir1" "D:\dir2"

# Explorer 右键「查找占用」（当前用户，可逆）
wholock --cli --register-shell
SAFETY FIRST

敢杀进程，更敢拦你

定位可以随便跑，处置必须层层设防——WhoLock 的护栏比它的功能更较真。

01

系统进程名单拦死

PID≤4、System、wininit、csrss、svchost、lsass、explorer、本进程——无论怎么点，直接拒绝，连确认框都不弹。

02

危险模式默认关

「启用危险操作」勾选框默认关闭且永不入库；按钮禁用态实时联动，不满足条件连门都摸不到。

03

逐次二次确认

结束进程与关闭句柄各自弹出完整上下文确认框（PID / 名称 / 路径 / 后果），看清楚了才放行。
