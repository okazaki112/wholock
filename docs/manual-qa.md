# manual-qa.md · WhoLock v0.1 人工验收清单（发版前逐项打勾）

> 用途：机检（check.ps1）只证明构建/依赖/纯逻辑正确；以下场景需要真机+真进程验证。自动化无法覆盖的交互语义全部在此闭环。

## A. 定位正确性
- [ ] A1 记事本→打开 `被占用.txt`→保存一次（保持写打开）→ 拖文件进窗口扫描：列表出现 `notepad.exe`；双击行 → Explorer 定位文件所在目录。
- [ ] A2 VS 工程文件被 MSBuild/VBCSCompiler 占用时扫描能报出对应 svchost/服务进程。
- [ ] A3 中文+空格+括号路径 `C:\用户 的(测试).dat`（用 powershell `[IO.File]::Open($p,'Open','ReadWrite','None')` 持锁 30s）扫描命中。
- [ ] A4 目标不存在 → 状态栏红区文案"文件不存在或无法访问…"非通用弹窗。
- [ ] A5 输入目录（D:\）→ 状态栏显示"仅支持文件目标"。

## B. 护栏与安全
- [ ] B1 未勾选危险模式点「结束选中进程」→ 状态栏给护栏提示，无 TerminateProcess。
- [ ] B2 勾选危险模式 + 选中 System(4)/未知进程 → MessageBox 拒绝。
- [ ] B3 勾选 + 选中普通进程 notepad → 确认框（含 PID/完整路径）；取消=无副作用；确认=进程结束且再扫消失。
- [ ] B4 对 explorer.exe 选择结束 → 被名单护栏拦下（ShellProcess 禁）。
- [ ] B5 非管理员运行：状态栏出现"当前非管理员"提示；以管理员重跑，同测试进程结果一致。

## C. UI 与免装
- [ ] C1 拖放路径回填自动触发扫描；窗口最小尺寸 640×430 不破版。
- [ ] C2 高 DPI 150% 缩放：字号与控件随 DPI 变化无重叠（DPI_AWARE PerMonitorV2 生效）。
- [ ] C3 大目录盘（10 万句柄级）点扫描→ 中途点取消返回"枚举被取消"，UI 不冻结。
- [ ] C4 Release `build\out\wholock.exe` 拷到无 VS/无 VC++ 运行时的 Windows 10/11 干净机（或 `sfc /verifyfile` 之外的虚拟机）双击可用。
- [ ] C5 `--cli --json` 输出可被 `ConvertFrom-Json` 解析（UTF-8 无 BOM）。

## D. 结束进程后续体验
- [ ] D1 结束后状态栏提示"重新扫描验证释放"；用户重扫 → 空结果 + 删除文件成功（记事本进程场景）。

## E. v1.0 新功能
- [ ] E1 勾选「深度扫描」后扫描：状态出现「深扫」引擎行；再次点击「取消」能在数秒内返回。
- [ ] E2 主列表选中进程 → 下方明细表自动填充该进程句柄（磁盘/管道分类、路径省略号）。
- [ ] E3 勾危险模式 + 明细选中【磁盘文件】句柄 → 确认框（含 PID/句柄号/路径）→ 释放后明细刷新该行消失。
- [ ] E4 结束进程成功 → 弹「释放后删除」询问 → YES → 状态「已删除：…」且文件在 Explorer 消失。
- [ ] E5 拖入一个目录 → 扫描状态显示「目录展开×1」；结果「占用文件」列定位到具体文件。
- [ ] E6 任务栏/标题栏/Alt-Tab 图标为蓝色"锁"字扁平图标。
- [ ] E7 `--cli --version` 输出 `WhoLock v1.0.0`；「关于」框同版本号。
- [ ] E8 深扫在含挂起句柄的环境中超时 → 状态明示"深扫超时，子进程已终止（保留部分结果）"且主窗不冻结。

## F. Explorer 右键集成（F12）
- [ ] F1 勾选「Explorer 右键集成」→ 状态"已启用"；在任意文件右键出现「查找占用(&W)」，点击后 GUI 启动并自动扫描该文件。
- [ ] F2 目录右键同样出现菜单项，点击后按目录展开扫描。
- [ ] F3 取消勾选 → 注册表键清理 → 右键菜单项消失。
- [ ] F4 把 exe 挪到别的目录 → 右键失效（指向旧路径）→ 在新位置勾选一次 → 右键修复并指向新路径。
